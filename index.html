Perguntas Frequentes

O evento é para toda a família?

Sim! Temos brinquedos infláveis e programação pensada para crianças o dia todo. Toda a família é bem-vinda.

Como faço para ser expositor ou patrocinador?

Manda uma mensagem pra gente no Instagram — contamos os próximos passos por lá.

Como funciona o sorteio do iPhone 18 Pro?

O regulamento completo está na publicação oficial no Instagram — dá uma olhada lá pra saber como participar.

Como chego até Sarcelles?

O endereço é 17 Rue de l'Escouvrier, 95200 Sarcelles. Use o botão "Como Chegar" na seção Local para abrir a rota no Google Maps a partir de onde você estiver.
