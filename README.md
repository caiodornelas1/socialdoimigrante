# Social do Imigrante

Landing page mobile-first do "Social do Imigrante" — festa anual da comunidade brasileira em Paris.

## Stack

HTML/CSS/JS puro, sem framework, sem build step.

## Rodando localmente

Qualquer servidor estático funciona, por exemplo:

```bash
npx serve .
```

Depois abra `http://localhost:3000` (ou a porta indicada).

## Estrutura

```
index.html
css/styles.css
js/script.js
assets/
  video/hero.mp4       — vídeo de fundo do hero (loop, sem som)
  logos/                — logos oficiais do evento
  flyers/                — flyers das edições anteriores
  legal/                  — política de privacidade/cookies (placeholder)
```
